APP - MySQL - purge binlog files
--------------------------------
REF: https://dba.stackexchange.com/questions/233048/my-disk-is-full-of-binlog-files
REF: https://www.vinchin.com/database-tips/mysql-bin-files-filling-up-disk.html

-I noticed on one of my systems there were a lot of binlog files.

-How to log into MySQL

SH> mysql -u root -p

** WILL NOT BE ABLE TO LOG ON IF THERE IS 0% OF DISK FREE.  IF THAT IS THE CASE, FREE SPACE FIRST **

-How to show log files:

mysql> SHOW BINARY LOGS;

-How to purge logs older thatn 7 days:

mysql> PURGE BINARY LOGS BEFORE DATE(NOW() - INTERVAL 7 DAY) + INTERVAL 0 SECOND;

-Flush logs after purging

mysql> FLUSH LOGS;

SH> mysql -u root -p -e SHOW VARIABLES LIKE 'log_bin_basename';

-Used the following command to clean it up:

SH> mysql -u root -p -e "PURGE BINARY LOGS BEFORE '2026-02-15 10:06:06';

SYSTEM - Setting / Changing Timezone
------------------------------------
REF: https://linuxconfig.org/ubuntu-24-04-change-timezone

-It looks like Ubuntu 24 during install, will not ask for timezone, so we need to set it manually

-Check Timezone:
UBUNTU> timedatectl

-Set Timezone to New_York
UBUNTU> sudo timedatectl set-timezone America/New_York

SYSTEM - Finding and killing zombie processes
---------------------------------------------
REF: https://itsfoss.com/kill-zombie-process-linux/

-run top to look at processes
SH> top
Press Z to see them

or use the following commands

SH> ps -A -ostat,pid,ppid | grep -e '[zZ]'
-This will output a list of processes with 3 columns, and use the value in the 3rd column to kill all of them
SH> kill -9 <PPID>

---------------------------

NETWORK - Set or change DNS server (Ubuntu 18.04)
-------------------------------------------------
Date: 2024.09.09

REQUIRED: <DNS_NEW>
OPTIONAL: <DNS_OLD>

-Log onto server
-SH> sudo nano /etc/netplan/00-installer-config.yaml
-Look for nameserver: addresses:
-Change IP address from <DNS_OLD> to <DNS_NEW>
-Exit Nano and save value
-SH> sudo netplan apply
